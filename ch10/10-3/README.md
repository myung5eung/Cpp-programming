# 실습과제1
### STL 라이브러리에서 컨테이너 클래스, 이터레이터 클래스, 알고리즘 함수의 역할을 각각 설명하시오.
- 컨테이너 클래스는 데이터를 저장하는 자료구조를 구현한 템플릿 클래스
- 이터레이터 클래스는 컨테이너의 원소를 가리키는 포인터를 관리하여 컨테이너의 원소에 접근
- 알고리즘 함수는 컨테이너의 원소에 대해 복사, 검색, 삭제, 정렬 등의 처리를 수행하는 템플릿 함수이다. 알고리즘 함수는 컨테이너의 멤버 함수가 아닌 전역 함수로 구현
### 포인터와 iterator의 공통점과 차이점은 각각 무엇인가?
- 공통점: 둘 다 메모리의 특정 위치를 가리키며 간접 참조 연산자 `*`를 이용하여 가리키는 값에 접근할 수 있다. 또한 증가 연산자를 이용하여 다음 원소로 이동 가능
- 차이점: 포인터는 C++ 언어의 내장 기능으로 메모리 주소를 직접 저장하고 처리하지만 iterator는 컨테이너의 원소를 가리키는 포인터를 관리하는 클래스의 객체이다.

### vector 클래스의 erase, insert 멤버함수의 매개변수, 리턴값, 기능을 설명하시오.
- erase
  - 매개변수: 삭제할 원소를 가리키는 iterator
  - 기능: iterator가 가리키는 원소를 삭제
  - 리턴값: 삭제된 원소의 다음 원소를 가리키는 iterator를 반환
- insert
  - 매개변수: 삽입할 위치를 가리키는 iterator와 삽입할 원소
  - 기능: iterator가 가리키는 위치에 원소를 삽입
  - 리턴값: 삽입된 원소를 가리키는 iterator를 반환

### vector::end() 함수는 마지막 원소의 다음 원소를 가리키는 iterator를 반환하는가?
 end() 함수는 벡터의 마지막 원소 자체가 아니라 마지막 원소의 다음 위치를 가리키는 iterator 객체를 반환

### Iterator 객체를 이용한 반복문에서 조건문에 `it != v.end();` 대신에 `it <= v.end();`를 쓰면 어떻게 되는가?
